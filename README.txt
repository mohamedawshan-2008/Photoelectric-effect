PHOTOELECTRIC LAB - Android project (works offline)

BUILD THE APK ONLINE WITH GITHUB (no installs)
 1. Create a new repository on github.com (name: PhotoelectricLab, Public).
 2. Upload everything inside this folder. If the hidden .github folder does
    not upload: Actions tab > "set up a workflow yourself", paste the text of
    build-workflow-copy.yml, and commit.
 3. Wait 3-5 minutes in the Actions tab for a green tick.
 4. Open the run, download "PhotoelectricLab-APK", unzip it -> app-debug.apk.
 5. Copy the APK to the smart board / phone (USB, Bluetooth, or Google Drive),
    tap it, and allow "install unknown apps".

To change the app, edit app/src/main/assets/index.html.
